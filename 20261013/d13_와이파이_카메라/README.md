# D13 Wi-Fi와 카메라 — 보드가 인터넷 동네에 들어가고, 눈(카메라)을 뜬다

보드(ESP32-CAM)가 공유기에 붙어 주소(IP)를 받고, **보드가 웹 서버가 되어** PC 브라우저가 `http://보드주소` 로 찾아옵니다. 여러분 PC 는 유선이고 Wi-Fi 에 붙는 것은 보드뿐입니다. 카메라는 **카메라 포함 펌웨어**를 구워야 쓸 수 있습니다(3교시).

| 파일 | 한 줄 설명 | 조작 |
|---|---|---|
| `w1_wifi_scan.py` | 주변 Wi-Fi 목록(이름·채널·신호·보안) | 실행만 하면 된다 |
| `w2_wifi_connect.py` | 공유기에 접속하고 IP·서브넷·게이트웨이·DNS 읽기 | `SSID` · `PASSWORD` 를 수업에서 안내한 값으로 바꿔 실행 |
| `w3_web_flash.py` | 보드가 웹 서버: 브라우저에서 `/on` · `/off` 로 플래시 | 같은 두 줄을 바꿔 실행, 쉘에 나온 주소를 브라우저에 입력 |
| `c1_cam_capture.py` | 브라우저에서 사진 한 장(`/capture`) | **카메라 펌웨어를 올린 뒤** 같은 두 줄을 바꿔 실행 |
| `c2_cam_stream.py` | 브라우저에서 실시간 영상(`/stream`), `SIZE` · `QUALITY` 를 바꿔 속도 비교 | c1 과 같은 방법 |
| `펌웨어/` | 카메라 포함 펌웨어와 굽기 · 원복 파일 (`펌웨어_굽기.bat`, `펌웨어_원복.bat`) | 폴더 안 `README.md` 와 수업 슬라이드를 따른다 |

## 주의
- **Wi-Fi 이름과 비밀번호는 이 저장소에 적혀 있지 않습니다.** 파일의 `여기에_…` 자리를 수업에서 알려 주는 값으로 바꿔 쓰고, 바꾼 파일은 저장소에 올리지 않습니다.
- 펌웨어를 굽기 전에 **Thonny 를 완전히 끄고 보드는 한 대만** 꽂습니다.
- 카메라 영상은 같은 공유기에 있는 사람이 주소를 알면 누구나 볼 수 있습니다. 수업이 끝나면 정지해 둡니다.
- **플래시를 눈으로 직접 보지 말 것**(매우 밝다).
