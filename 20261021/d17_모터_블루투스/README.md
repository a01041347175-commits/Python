# D17 모터 블루투스 제어 — 폰이 보낸 숫자 0~200 으로 모터 네 개를 켜고 끈다

앞 수업에서 만든 코드 조각을 **레고처럼 이어 붙여** 한 단계씩 만든다. 파일 순서대로 따라 한다.

| 순서 | 파일 | 하는 일 | 끝났다는 표시 |
|---|---|---|---|
| 0 | `m0_motor_check.py` | 모터 네 개를 약하게 1초 켠다 | 쉘에 모터 꺼짐 |
| 1 | `m1_ble_number.py` | 폰이 보낸 숫자를 받아 목표 듀티로 정한다 (모터 없이) | 쉘에 목표 듀티 = 보낸 숫자 |
| 2 | `m2_set_duty_now.py` | 받은 숫자를 **바로** 모터 듀티로 준다 | 숫자를 보내면 모터가 바로 바뀌고 0 이면 꺼진다 |
| 3 | `m3_ramp_isr.py` | **고급** — 인터럽트 깃발(10·100·500ms) 위에서 100ms 마다 1씩 목표로 다가간다 | 모터가 부드럽게 커졌다 작아지고 0 에서 꺼진다 |

- `참고소스/` 폴더에 앞 수업에서 쓴 원본 코드가 들어 있다 (교재 2-4, 3-1, `c4c_isr_flags.py`, `c6_pwm_fade.py`, `c7_pwm_range.py`, `e3_ble_flash_control.py`).
- `ble_simple_peripheral.py`, `ble_advertising.py` 는 보드에 올려 둔 것과 같다 (이미 올렸으면 다시 올리지 않아도 된다). 이 파일 안에 그때 직접 쓴 복잡한 블루투스 코드가 들어 있어, 오늘은 3줄만 쓴다.
- 위쪽 `★ 고쳐 쓰는 값` 칸의 숫자만 바꾸면 동작이 달라진다: `STEP`, `MAX_DUTY`, `INPUT_MODE`.
- **처음에는 프로펠러를 빼고, 듀티 100 이하에서** 시험한다. 멈추기는 Ctrl+C.
