# D12 버튼 마무리와 블루투스 — 양산 제품 방식 디바운스, 폰과 말하기

입력은 **IO0 버튼 하나**(GPIO0, 안 누르면 1 · 누르면 0), 출력은 **플래시**(GPIO4)와 **빨간 LED**(GPIO33, 0 이 켜짐)입니다. 3~4교시는 **휴대폰 앱 nRF Connect for Mobile** 로 보드와 블루투스(BLE)로 말합니다. 이 폴더에는 오늘 하루치 코드가 모두 있습니다.

| 파일 | 한 줄 설명 | 조작 |
|---|---|---|
| `b1_button_read.py` | 버튼 값을 읽어 눌림·뗌을 글자로 찍는다 | 눌렀다 뗀다 |
| `b2_button_led.py` | 누르는 동안 플래시가 켜진다 | 누른다 |
| `b3_button_toggle_timer.py` | 인터럽트 구조 위에서 10ms 마다 버튼 확인, 눌린 순간 플래시 토글 | 누를 때마다 토글 |
| `b4_button_debounce.py` | **양산 제품 방식 디바운스** — 0 도 1 도 `DEBOUNCE_MS = 70` 동안 안정돼야 인정하고, 눌렀다 뗀 한 바퀴(1 → 0 → 1)가 확정될 때 플래시 토글 | 누르고 떼기, 열 번 눌러 인정된 횟수 확인 |
| `b4_long_press_answer.py` | (심화 정답) 5초 이상 누르면 무효로 만든다. **먼저 직접 해 보고 막히면 연다** | 5초 넘게 누르고 뗀다 |
| `g1_flashlight.py` | 스마트 손전등: 꺼짐→약→중→강→꺼짐 | 누를 때마다 한 단계 |
| `g2_dimmer_breath.py` | (도전·심화) 디머와 호흡등 | 짧게 = 켜짐/꺼짐, 길게 = 밝기 조절 |
| `g3_reaction_game.py` | 반응속도 게임 | 안내에 따라 누르기 |
| `e1_ble_advertise.py` | 보드가 자기 이름을 알린다 (광고) | 폰 앱 Scanner 목록에서 내 이름 찾기 |
| `e2_ble_button_notify.py` | 연결한 폰으로 버튼 눌림을 알린다 (TX 알림) | 앱에서 TX 알림을 켜고 IO0 누르기 |
| `e3_ble_flash_control.py` | 폰이 RX 에 `1` / `0` 을 써서 플래시를 켜고 끈다 | 앱에서 RX 에 글자 쓰기 |

## 블루투스 파일을 쓸 때
- 파일 4번째 줄 `NAME = "CAM-00"` 을 **내 번호로 바꾼다** (예: `CAM-07`). 20대가 동시에 이름을 알리므로 겹치면 내 보드를 못 찾는다.
- 폰 앱에서는 서비스 번호 `6E400001…`(Nordic UART Service) 안에서, 보드→폰은 `6E400003…`(TX), 폰→보드는 `6E400002…`(RX)를 쓴다. 이 번호는 모든 보드가 같다.
- e1 → e2 → e3 순서로 하나씩 실행한다. 한 보드에서 두 코드가 동시에 돌 수 없으니 이전 것은 정지(Ctrl+C)한다.

## 주의
- **플래시를 눈으로 직접 보지 말 것**(매우 밝다). 책상이나 벽을 비추게 놓는다.
- **IO0 는 부팅 스트랩 핀**: 보드 전원을 켜거나 리셋하는 중에는 버튼을 누르지 않는다. 부팅이 끝난 뒤에 누른다.
- 파일 하나로 완결되어 있으니 실행할 파일 하나만 Thonny 에서 열어 실행한다. 끝내려면 정지(Ctrl+C).
