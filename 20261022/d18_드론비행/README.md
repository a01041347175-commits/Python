# D18 드론 비행 — 앱으로 읽고, 보정하고, 날린다 (교재 3장)

보드는 **pyDrone 펌웨어(v1.18)** 상태여야 한다. 토니 쉘 첫 줄에 `01Studio PYDRONE`, `import drone` 이 되면 맞다.
프로펠러는 **3교시까지 빼 둔다.** 코드를 고치거나 파일을 올릴 때는 언제나 프로펠러를 뺀 상태에서 한다.

| 교시 | 파일 | 하는 일 |
|---|---|---|
| 1 | `f5_OLED_상태.py` | 배터리 전압·퍼센트를 OLED 에 보여 준다 |
| 2 | `f1_받기.py` → `f2_칸별로.py` → `f3_조종값.py` | 폰 앱이 보낸 8바이트를 읽는다 (모터는 돌지 않는다) |
| 3 | `f4_보정과_상태.py`, `main_비행/main.py` | 보정, 앱 조종 코드 (프로펠러 없이) |
| 4 | `main_비행/main.py`, `route_자동경로/main.py` | 앱 비행, 자동 경로 (강사 허가 뒤) |

- 라이브러리 `ble_advertising.py`, `ble_simple_peripheral.py`, `ssd1306.py` 는 보드에 올려 둔다.
- 코드 위쪽 `NAME = 'pyD_01'` 은 **내 번호**로 바꾼다 (8글자 이하).
- 폰 앱 `[멈춤]` 은 자동 경로에서도 보정 중·비행 중·끝난 뒤 언제든 받는다. 긴급할 때 안전 담당이 "멈춤" 을 외치고 폰 담당이 앱 `[멈춤]` 을 누른다.
- `main_비행_끊김안전/` 은 선택이며 강사가 시험한 뒤에만 쓴다.
